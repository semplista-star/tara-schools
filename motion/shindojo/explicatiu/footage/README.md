# Metratge

Desa aquí el material real amb el nom del pla: `pla01.mp4`, `pla02.mov`, `pla05.jpg`…
(formats: mp4, mov, m4v, webm, jpg, jpeg, png, webp). Mira `../guio.md` per saber què cal gravar a cada pla.

- Vídeo horitzontal, idealment 1920×1080 o 4K, mínim tants segons com el pla + 1 s.
- Si el clip bo comença més tard, afegeix `"in": 12.5` al pla corresponent de `../shots.json`.
- Les fotos es mouen soles amb un zoom suau (Ken Burns).

Després executa `node motion/shindojo/explicatiu/scripts/build.mjs`.
